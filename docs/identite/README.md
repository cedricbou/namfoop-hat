# Identité visuelle

Les images de namfoop dont la carte a besoin : la bannière du README, les logos, l'onde, l'icône.
Ce sont des **copies conformes** de `docs/identite/` du dépôt
[namfoop](https://github.com/cedricbou/namfoop/blob/main/docs/identite/charte.md), dont la
**charte** fait référence : palette, polices, zone de protection, taille minimale, ce qu'on ne fait
jamais. Une image modifiée là-bas se recopie ici telle quelle ; on ne la redessine jamais ici.

| Fichier | Où s'en servir sur la carte |
| :--- | :--- |
| `banniere.svg` | haut du README |
| `logo-sombre.svg` | source du logo de sérigraphie (le blanc de la sérigraphie sur le vernis sombre) |
| `logo-clair.svg` | notice imprimée, emballage, fond clair |
| `onde.svg` | là où le mot ne tient pas (petite sérigraphie, façade) |
| `icone.svg`, `icone-128.png` | avatar, documentation |

Sur la carte : le logo complet ne descend pas sous 90 pixels à l'écran ni sous 30 mm en
sérigraphie ; il garde autour de lui un vide égal à la hauteur de la lettre `n`. Pour un boîtier ou
une façade, les couleurs et les polices sont celles de la charte (Chakra Petch pour le marquage).
